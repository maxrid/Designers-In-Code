Frame 09 / four habits

What keeps Claude Code honest

Click or press space to reveal

One fix per ask

Ask for two things, review five changes.

Say it like a Figma comment

Values and a file. Not "make it look better."

Keep the room small

Open the one file that matters. Less context, fewer inventions.

Read the diff, not the code

Right file, right values, nothing extra.

Frame 10 / three rules

One branch, one fix

Click or press space to reveal

Two bugs, two branches

A branch that does one thing gets reviewed in minutes. A branch that does five things sits for a week.

Name it for a stranger

What kind of change, slash, what it touches. fix/ or update/ covers most of what we do.

Open the PR the same day

Small change, quick review, no drift. A branch left alone for a week slowly stops matching main.

And never edit main directly. Main is where everyone lives.

Frame 11 / the line

Where I stop

Click or press space to reveal
Mine
  • Spacing, colour, type
  • Button states: hover, focus, disabled
  • The words and labels on screen
  • If I can point at it in a screenshot, it is mine
Not mine
  • Anything that calculates or decides
  • Anything that loads or saves data
  • Anything that changes more than one screen
  • Anything I cannot explain to the reviewer

A pull request is a request for someone's time. If my branch does not make main better, I delete it and nobody has to know.
